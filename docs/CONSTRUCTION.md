# 11 E 不动点入口与 14 E 完整单解

## 定义与免费输入

给定圆 Γ、圆心 O 及 A、B、C。目标对应固定为

```text
A on XY, B on YZ, C on ZX; X,Y,Z on Gamma.
```

把过给定点 P 的另一圆交点映射记为 I_P。
待求起始顶点 X 是 f=I_C I_B I_A 的不动点。
I_P 在圆上为一个射影对合；辅助相切处按重复交点理解，完整目标仍排除重复顶点。

三点输入何时无解、唯一、两解或无穷多解，以及 D₂ 的完整充要条件，见
[输入条件与解数分类](CLASSIFICATION.md)。

## 关键复用

由于 OA 经过圆心及 A，I_A 交换 U、V。又有

```text
I_B(U)=W, I_B(V)=R,
I_C(W)=V′, I_C(R)=U′,
I_A(W)=S, I_C(U)=S′.
```

因此已经知道 f 的三个点对：

```text
f(U)=U′, f(V)=V′, f(S)=S′.
```

最后一个关系使用 I_A(S)=W、I_B(W)=U，故
f(S)=I_C(I_B(I_A(S)))=I_C(U)=S′。
七条弦形成三个对应点对；不需要独立执行三次完整投影链。

对圆上射影对应 f，其交叉弦的交点

```text
UV′ ∩ U′V,
US′ ∩ U′S
```

位于同一条不动点轴上。这里 US′ 就是第 7 笔 CU，不必再画。
第 8–10 笔得到轴上 J、H，第 11 笔画出轴。
轴与 Γ 的交点就是 f 的不动点；第 12–14 笔恢复一个完整解。

## 独立代数证明

为证明旋转、平移和缩放后的整个一般参数族，可令 Γ 为单位圆，O=(0,0)，
A=(a,0)，a>0。此坐标规范仅用于证明；程序仍为 OA 支付第 1 E，
不免费得到任何坐标轴或圆周点。

采用圆的齐次有理参数

```math
P(u:v)=(v^2-u^2:2uv:v^2+u^2).
```

若 P=(x,y)，其另一交点映射的参数矩阵为

```math
M_P=\begin{pmatrix}y&x-1\\x+1&-y\end{pmatrix}.
```

设 T=M_C M_B M_A，则不动点轴系数成比例于

```math
\bigl(-(T_{12}+T_{21}),\ T_{22}-T_{11},\ T_{21}-T_{12}\bigr).
```

`verify_sage.py` 不导入构造器，在 QQ[a,bx,by,cx,cy] 中独立计算上述点、线，
验证 H、J 都落在该轴上，并且 JH 的齐次系数与该轴成比例。
另验证 JH 的齐次向量并非恒零。

## 一般位置范围

当前程序要求 A≠O；八个辅助圆周点 U,V,W,R,U′,V′,S,S′ 互异；
各笔定位点不同；J、H 是有限且不同的点，JH 是一条真正直线。
输入必须有两个不同、非退化的解。

这些中间条件经有理参数化和清分母可表示为有限个非零多项式条件。
符号轴关系和正常夹具证明它们并非恒等退化，故程序适用域在二解域中为
相对开稠密的一般位置子域。四个夹具是程序的精确重放证据；
不能用它们代替一般参数恒等式和上述适用条件。

当前未提供覆盖全部 D₂ 的分支修复，不能标为 rob；
也未验证最小性，不宣称 14 E 是理论最小。
