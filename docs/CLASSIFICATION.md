# 输入条件、存在性与解的个数

本文给出 Cramer–Castillon 问题的完整解数判定，并明确当前最短步数研究采用的
二解域 D₂。数学结论适用于本节约定范围内的任意实数输入，不要求一般位置。

## 1. 本文的问题约定

给定圆 Γ，圆心 O，半径 R>0，以及三个点 A、B、C，要求：

- A、B、C 互异、不共线，且均不在 Γ 上；允许给定点位于圆内、圆外或圆心。
- 求三角形 XYZ，三个顶点互异，且都在 Γ 上。
- A 位于直线 XY，B 位于直线 YZ，C 位于直线 ZX。
- 允许给定点在边的延长线上；不要求落在边的线段内部。

解数统计的是不同的几何三角形，不把顶点改名另算成一个解。
给定点不在圆上，因此同一点不可能同时落在一个非退化解的两条边所在直线上；
固定上述对应关系不会导致重复计数。

三点共线、给定点落在圆上、给定点重合的情形不在本文与当前 profile 的范围内。
它们不是自动无解，而是应当作为其他输入域另行讨论。

## 2. 两个判定量与一个特殊条件

### 2.1 判别式 K

定义三个点对 Γ 的幂：

```math
p_A=OA^2-R^2,\qquad p_B=OB^2-R^2,\qquad p_C=OC^2-R^2.
```

设 S 为三角形 ABC 的普通非负面积，定义

```math
\boxed{K=4R^2S^2+p_Ap_Bp_C.}
```

若已知坐标，令 a=A-O、b=B-O、c=C-O，则

```math
4S^2=\det(b-a,c-a)^2,
```

故可以直接计算

```math
K=R^2\det(b-a,c-a)^2
  +(a\cdot a-R^2)(b\cdot b-R^2)(c\cdot c-R^2).
```

K 在平移、旋转和反射下不变；整体缩放 λ 倍时变为 λ⁶K，符号不变。

### 2.2 自极条件：无穷多解的判定

称下列三个等式为自极条件：

```math
\boxed{a\cdot b=b\cdot c=c\cdot a=R^2.}
```

几何上，这等价于 A 的极线是 BC、B 的极线是 CA、C 的极线是 AB。
在本文范围内，自极条件当且仅当有无穷多个非退化解。此时 K=0。
必须先检查这一项，不能把它并入有限解的减法公式。

### 2.3 退化候选数 e

定义三个非负整数：

- e_A：从 A 向 Γ 作切线时，落在直线 BC 上的不同切点个数。
- e_B：从 B 向 Γ 作切线时，落在直线 CA 上的不同切点个数。
- e_C：从 C 向 Γ 作切线时，落在直线 AB 上的不同切点个数。

令

```math
\boxed{e=e_A+e_B+e_C.}
```

圆内点没有实切点，相应 e_P=0。圆外点的 e_P 可以是 0、1、2。
不需要实际作出切线，也可以用极线和相交关系精确计算：

1. 若 A 在圆内，取 e_A=0。
2. 若 A 在圆外，令其极线为

   ```math
   \ell_A:\ (A-O)\cdot(P-O)=R^2.
   ```

3. 若 ℓ_A 与 BC 平行而不重合，e_A=0。
4. 若 ℓ_A=BC，e_A=2。
5. 否则求唯一交点 D=ℓ_A∩BC；D 在 Γ 上时 e_A=1，否则 e_A=0。

对 B、C 循环执行。实现见 [classify_sage.py](../experiments/classify_sage.py)。
这里的输入分析不为作图程序赠送极线、切线或任何新点；若程序实际绘制它们，
仍须展开并计 E。

## 3. 完整解数表

首先检查自极条件，满足时解数为无穷多。

不满足自极条件时，解数 N 为：

| 条件 | 圆上的闭合候选数 | 退化候选数 | 非退化解数 N |
|---|---:|---:|---:|
| K<0 | 0 | 0 | **0** |
| K=0，e=0 | 1 | 0 | **1** |
| K=0，e=1 | 1 | 1 | **0** |
| K>0，e=0 | 2 | 0 | **2** |
| K>0，e=1 | 2 | 1 | **1** |
| K>0，e=2 | 2 | 2 | **0** |

非自极时不会出现表外的 e 值：K=0 时 e≤1；K>0 时 e≤2。

因此，三个点满足什么条件时有解，可以直接写成以下充要条件。

**至少有一个非退化解：**

```math
\boxed{\text{自极条件成立}\quad\text{或}\quad
(K=0,\ e=0)\quad\text{或}\quad(K>0,\ e\le1).}
```

**恰有唯一解：**

```math
\boxed{\text{非自极，且}\quad
\bigl[(K=0,\ e=0)\quad\text{或}\quad(K>0,\ e=1)\bigr].}
```

**恰有两个解：**

```math
\boxed{K>0,\qquad e=0.}
```

**无解：**

```math
\boxed{K<0\quad\text{或}\quad
\bigl(\text{非自极},K=0,e=1\bigr)\quad\text{或}\quad(K>0,e=2).}
```

**无穷多解：**

```math
\boxed{a\cdot b=b\cdot c=c\cdot a=R^2.}
```

## 4. 三个点都在圆内时的简化

此时三个 e_P 都等于零，也不可能满足自极条件，所以：

| 条件 | 非退化解数 |
|---|---:|
| K<0 | 0 |
| K=0 | 1 |
| K>0 | 2 |

即有解当且仅当 K≥0，唯一解当且仅当 K=0。
仅有“三点互异且不共线”不能保证有解。

## 5. 为什么是这个判别式

### 5.1 闭合条件与不动点

对不在 Γ 上的给定点 P，令 I_P 把圆上一点映到直线 P 与该点所确定的
另一圆交点。相切时按同一个点理解。I_P 是圆上的射影对合。

候选三角形的闭合条件是

```math
f(X)=X,\qquad f=I_CI_BI_A.
```

暂时允许顶点重合时，不动点与闭合候选一一对应。

### 5.2 固定点方程

平移、缩放到单位圆，记归一化坐标为 a,b,c，使用参数

```math
P(u:v)=(v^2-u^2:2uv:v^2+u^2).
```

给定点 p=(x,y) 对应矩阵

```math
M_p=\begin{pmatrix}y&x-1\\x+1&-y\end{pmatrix},\qquad
T=M_cM_bM_a=\begin{pmatrix}\alpha&\beta\\\gamma&\delta\end{pmatrix}.
```

各点不在圆上保证每个矩阵可逆。不动点是实射影直线上的二次方程

```math
\gamma u^2+(\delta-\alpha)uv-\beta v^2=0
```

的根；采用齐次坐标也包含参数为无穷远的普通圆周点，不会漏解。
除非 T 是非零标量矩阵，其判别式为

```math
\Delta=(\operatorname{tr}T)^2-4\det T.
```

直接展开可得

```math
\operatorname{tr}T=2\det(b-a,c-a),\qquad
\det T=-(|a|^2-1)(|b|^2-1)(|c|^2-1),
```

从而回到原始尺度后

```math
\boxed{\Delta=\frac{4K}{R^6}.}
```

所以非恒等对应有 0、1、2 个闭合候选，分别对应 K<0、K=0、K>0。

### 5.3 恒等对应与自极条件

T 是非零标量矩阵时，所有圆周点都不动。T 为标量矩阵当且仅当自极条件成立。
一种验证方式是使用

```math
M_p^2=(|p|^2-1)I,\qquad
\operatorname{tr}(M_pM_q)=2(p\cdot q-1).
```

若 T 为标量矩阵，由可逆性及循环重排可推出三个点积都等于 1。
反过来，将三个点积等于 1 代入，T 的非对角元及两对角元之差都为零。
这些等式已由 Sage 在六个独立坐标参数的多项式环中验证。

恒等对应中仍有有限个切线退化起点需要排除，但剩余的非退化解仍然有无穷多个。

### 5.4 为什么恰好扣除 e

若一个闭合候选满足 X=Y=P、Z≠P，则 AP 是圆在 P 的切线；
同时直线 PZ 经过 B、C，因此 P∈BC。这正是 e_A 所统计的切点。
反过来，每一个这样的切点 P 都给出唯一的这种退化闭合候选。
BC 不可能也是 P 处的切线，否则 A、B、C 共线，违背约定。

同理，Y=Z 对应 e_B，Z=X 对应 e_C。
三类退化不会重叠：若一个候选同时满足两种顶点重合，则三个顶点全相同，
三个给定点都落在同一条切线上，再次违背不共线条件。
因此非自极时，有限闭合候选数减去 e，恰好是真正的解数。

## 6. 覆盖全部分支的精确例子

以下均为 O=(0,0)、R=1；所有输入坐标均为有理数。

| 情形 | A | B | C | K | e | 解数 |
|---|---|---|---|---:|---:|---:|
| 判别式为负 | (0,0) | (1/2,0) | (0,1/2) | -1/2 | 0 | **0** |
| 唯一非退化重根 | (1/2,1/2) | (-3/10,1/10) | (1/5,-2/5) | 0 | 0 | **1** |
| 两个正常解 | (2,0) | (0,3) | (-2,-2) | 424 | 0 | **2** |
| 两候选中一个退化 | (1,1) | (2,0) | (0,0) | 1 | 1 | **1** |
| 两候选全部退化 | (2,0) | (1/2,0) | (1/2,1) | 27/16 | 2 | **0** |
| 唯一候选退化 | (1,1) | (2,0) | (1/2,0) | 0 | 1 | **0** |
| 自极构型 | (3/5,0) | (5/3,4/3) | (5/3,-4/3) | 0 | 4 | **∞** |

最后一行先按自极条件返回无穷多，绝不执行“1−4”的有限减法。

第 4 行还说明：唯一解不仅可能出现在 K=0 时，K>0 时也可能因一个候选退化而唯一。
第 5 行说明：K>0 不保证有真正的三角形。

## 7. 本项目的二解域与构造覆盖范围

在第 1 节的输入约定下，当前研究域严格为

```math
\boxed{D_2=\{(\Gamma,O,A,B,C):K>0,\ e=0\}.}
```

它保证恰有两个不同的非退化目标三角形，但不保证某一份具体辅助作图不会出现
平行线、辅助点重合等中间退化。当前 14/17 E 程序还须满足
[CONSTRUCTION 的一般位置条件](CONSTRUCTION.md#一般位置范围)。
输入有解、解有几个、某份算法是否适用、算法需要几 E，是不同的判定。
