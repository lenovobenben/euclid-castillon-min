# 研究路线与后续工作

## 当前基线

一般位置下完整单解 14 E、完整双解 17 E；只构造顶点分别为 13、15 E。
当前新增圆数为零。证据包括逐笔依赖、一般参数恒等式、独立 Sage 精确重放。
尚未证明全局最小，尚未给出整个 D₂ 的鲁棒上界。

AB 严格割圆的子域已有 [12 E 完整单解、15 E 完整双解](SECANT.md)，
对应顶点目标为 11、13 E。整个 D₂ 中也存在 AB、BC、CA 均不割圆的开子域。
进一步筛查了 625 个 AB 起步弦线前缀及固定前缀后的 98,653 个两笔混合状态，
五个数值初筛结果全部被独立精确核验排除，范围见 [SEARCH](SEARCH.md)。

## 优先级

1. **整个 D₂ 一般位置的完整单解降到 13 E 或以下。** 优先处理严格割线构造的覆盖缺口，
   并比较直接得到目标顶点的路线。
2. **扩大前缀。** 加入以已有线线交点为定义点的弦和混合基础圆，保留跨夹具阳性校准。
3. **双解共享。** 独立优化全部六个顶点和全部六条边，复用对象但不免除实际重复绘制。
4. **退化修复。** 按辅助点合并、定义线平行、H/J 合并等分类，记录完整 D₂ 最坏成本。
5. **下界。** 只有搜索规则与候选空间的完备性得到证明后，才讨论最小性结论。

已有搜索范围和未覆盖的候选见 [SEARCH](SEARCH.md)。重跑同一范围前，应先提出新的
起始状态、预算、候选形状或接回完整程序的接口。

## 发布与复现

- 保持中英文 README 的步数、输入条件和证据等级一致。
- 软件 Apache 2.0、数学内容与研究数据 CC BY 4.0；保留第三方出处。
- 结果写入 `experiments/results/`，同时提供再生成命令。
- 不将一个方便的固定实例成绩直接推广为一般位置或鲁棒成绩。
